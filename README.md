# Smart Financial Evaluation & Simulator System (C++)

A simple and interactive terminal-based system built in C++ to help users evaluate financial options and simulate monetary decisions. The system processes user inputs to provide real-time calculations and eligibility assessments.

## Key Features

* **Loan & Credit Eligibility Checker:** Uses clear conditional flow (`if-else` structures) to evaluate applicant risk based on age, income, and debt ratios.
* **Income Tax & Net Salary Calculator:** Calculates progressive tax deductions and net payout based on income slabs.
* **Investment Yield Evaluator:** Simulates potential investment returns over variable tenures and interest tiers.
* **Basic Input Validation:** Ensures user entries conform to expected numerical bounds before processing calculations.

## Technical Stack

* **Language:** C++
* **Core Concepts:** Input/Output Streams (`cin`, `cout`), `if-else` conditional statements, Switch-case, and Modular Control Flow.
